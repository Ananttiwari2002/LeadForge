The honest boundary

What a static front-end
cannot do.

Three capabilities sit genuinely outside this deliverable. Naming them is part of the feasibility study, not an omission.

01

Live data collection

Searching platforms and pulling company data needs a permitted data source, a backend worker, and a legal basis. A browser page cannot do this responsibly.

02

A real AI model

Summarising evidence or ranking records with a model needs an API key, cost control and evaluation. The prototype demonstrates the workflow with rules instead.

03

Accounts and a database

Authentication, permissions, audit logging and durable storage are server concerns. The front-end is deliberately built so an API can drop in behind it.
