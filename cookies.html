Project notes / Cookies

No cookie jar
in this concept.

The LeadForge frontend does not intentionally set cookies or use browser storage for tracking.

Concept note / November 2026

Prototype scopeThis note describes the static files in this workspace. A production site's hosting, embedded content, and third-party services could change how cookies and similar technologies are used.

Current behavior

The provided HTML, CSS, and JavaScript do not set cookies, use local storage or session storage, or include advertising and analytics scripts. The mobile menu and lead sample filters operate in page memory only. The local feedback preview clears its fields after confirmation and makes no submission.

Hosting environment

If these files are placed on a web server, that host may use essential cookies or collect technical request logs. The operator of that hosting environment must check its own configuration, explain any such processing, and distinguish it from the frontend behavior described here.

Future changes

Adding sign-in, analytics, embedded media, personalization, external fonts, or other third-party tools may introduce cookies or similar storage. Reassess the notice and consent requirements before adding such features.

Legal review

This explanatory note is not legal advice or a jurisdiction-specific cookie policy. Obtain qualified review before public launch, especially if the site uses non-essential cookies, analytics, or third-party services.
